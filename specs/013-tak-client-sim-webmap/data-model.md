### After

```python
class ClientConfig(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    host: str = "tak-server"
    port: int = Field(default=8089, ge=1, le=65535)
    use_ssl: bool = True             # ← NEW: False = plaintext TCP (for tak_relay.py)
    use_ssl_verify: bool = False
    ca_bundle: Optional[str] = None
    max_retries: int = Field(default=0, ge=0)
    # ... (remaining fields unchanged)
```

### Field specification

| Field | Type | Default | Validation | Description |
|-------|------|---------|------------|-------------|
| `use_ssl` | `bool` | `True` | Pydantic bool coercion | When `True` (default), wraps the TCP connection in a TLS/SSL context via `build_ssl_context()`. When `False`, passes `ssl=None` to `asyncio.open_connection` for plaintext TCP — required for connecting to `scripts/tak_relay.py`. |

### Backward compatibility
- Default is `True` — all existing YAML configs that omit `use_ssl` continue to use SSL.
- `extra="forbid"` is preserved — unknown fields in YAML still raise a `ValidationError`.
- `frozen=True` is preserved — config is immutable after construction.

## `connection.py` — conditional SSL

**File**: `services/tak-client-sim/src/tak_client_sim/connection.py`

### Change in `connect_with_retry()`

```python
# Before:
ssl_ctx = build_ssl_context(config)

# After:
ssl_ctx = build_ssl_context(config) if config.use_ssl else None
```

`asyncio.open_connection(..., ssl=None)` uses a plain TCP socket (no TLS handshake). The existing `except (OSError, ssl.SSLError, ConnectionRefusedError)` handler covers both SSL and plaintext error cases.
